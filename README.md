## ai-fitness-coach
AI-powered fitness planning and workout tracking web application

# Problem Statement
An intelligent fitness platform that generates personalized workout plans, tracks progress, and adapts
recommendations based on user goals, performance, and feedback

# MVP Features

- AI Assistance
- AI personalized workout plans

# Tech Stack
- Frontend: React + Typescript
- Backend: FastAPI + Python
- Database: PostgreSQL
- AI Integration: OpenAI
