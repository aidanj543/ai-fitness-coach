# ai-fitness-coach
AI-powered fitness planning and workout tracking web application

# Problem Statement
An intelligent fitness platform that generates personalized workout plans, tracks progress, and adapts
recommendations based on user goals, performance, and feedback

# MVP Features

- AI Assistance
- AI personalized workout plans
- Authentication
- Workout Tracking
- Progress Visualization

# Tech Stack
- Frontend: React + Typescript
- Backend: FastAPI + Python
- Database: PostgreSQL
- AI Integration: OpenAI

## Local Development

### Frontend

Requirements:
- Node.js
- npm

1. Clone the Repository
2. Navigate into the frontend directory
3. Install Dependencies
4. Start the Development Server

Commands:

```bash
cd frontend
npm install
npm run dev 
```

## Backend Development

## Requirements
- Python 3.11+


## Setup
1. Navigate to the Backend Directory
2. Create a Python virtual environment
3. Activate the virtual environment
4. Install dependencies
5. Start the FastAPI development server
